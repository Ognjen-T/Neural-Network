# Neural Network

A small experiment in building intelligence from first principles. Every version is a step toward understanding how learning emerges from simple rules.

### Current progress
v1.0 — Single artificial neuron
- One input → one neuron → one output
- Weight and bias learning
- Gradient-descent-style updates
- Error and loss calculation
- Adjustable learning rate
- Training loop with convergence
- Training time measurement

Next: train on multiple examples and build the first hidden layer.
