# Neural Network

A neural network built from scratch in Python to understand how neural networks learn, one version at a time.

## Current Progress

### v1.2 — Hidden Layer Forward Pass

- Added configurable number of hidden neurons
- Added random weight and bias initialization
- Added ReLU activation
- Added output layer
- Added forward-pass prediction
- Added loss calculation
- **Not yet using backpropagation**
- **Weights currently do not update**

## Next Step

**v2.0 — Backpropagation**

Teach the network how to update its weights and biases based on the error.
